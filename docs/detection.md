# LiDAR 처리와 장애물 감지

`detector_node`가 `/scan`을 받아 `front_min_distance()`로 전방 최소 거리를 계산하고 `/obstacle/front_distance`로 발행한다. 계산은 이 함수 한 곳에만 둔다.

## 전방 구간

라이다는 5 Hz, 360 샘플, `angle_min`=0, 측정 범위 0.12 ~ 3.5 m다(`model.sdf`). 0번 샘플이 정면이므로 앞쪽 인덱스(왼쪽)와 뒤쪽 인덱스(오른쪽)를 합쳐 전방 구간을 만든다. `front_deg`=30이면 인덱스 0~15와 345~359다.

`max_angle`이 2π가 아니라 6.28이어서 샘플 간격은 약 1.0023도다. 그래서 인덱스 345는 -14.21도이고, 오른쪽 경계가 왼쪽(+15.03도)보다 약 0.8도 좁다. 샘플 한 칸보다 작은 차이다.

## 특수값 처리

| 값 | 뜻 (REP 117) | 처리 |
|---|---|---|
| 유한값, 범위 안 | 측정값 | 후보 |
| 유한값, 범위 밖 | 신뢰할 수 없음 | 제외 |
| `+inf` | 범위 안에 물체 없음 | 제외 |
| `-inf` | 측정하기엔 너무 가까움 | 후보 (최소값이 되어 `-inf` 반환) |
| `NaN` | 측정 오류 | 제외 |

| 전방 구간 상태 | 반환 | 발행 | `avoider` 동작 |
|---|---|---|---|
| 유효값 있음 | 최소값 | 발행 | 거리별 상태 전환 |
| `-inf` 포함 | `-inf` | 발행 | 후진 후 회전 |
| 유효값 없음 | `inf` | 발행 | 전진 |
| 전체 `NaN` | `None` | 안 함 | 수신 끊김으로 안전 정지 |
| `angle_increment` 이상 | `None` | 안 함 | 수신 끊김으로 안전 정지 |

## 알려진 한계

- 전방 구간 밖의 장애물은 감지하지 않는다. 회전 중 측면 접촉은 막지 못한다.
- `Float32`에 타임스탬프가 없어 `detection_log`는 수신 시각으로 스캔과 토픽을 짝짓는다.
